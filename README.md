# Installation

1. Download the addon by clicking the link below:
   - [Download Leatrix Plus](https://github.com/ggb00/Leatrix_Plus/archive/refs/heads/main.zip)
2. Unzip the downloaded archive.
3. Rename the folder inside the zip from `Leatrix_Plus-main` to `Leatrix_Plus` (folder name should be the same as `.toc` file).
4. Move the `Leatrix_Plus` folder to your World of Warcraft AddOns folder.
    - Example: `C:\World of Warcraft WotLK\Interface\AddOns`
5. If you have WoW open - restart the game for the addon to load in properly.

## Usage
<sup>Instead of `/ltp` you can use `/lea` or `/leatrix`</sup>\
`/ltp`, `/lea`, `/leatrix` — chat command to open options menu for Leatrix Plus.\
`/ltp wipe` — chat command to completely wipe your Leatrix Plus settings.\
`/ltp resetchat` - chat command to reset chat window position.
